## อัปเดตเกมขึ้นเว็บ

ดับเบิลคลิกไฟล์ `อัปเดตเกม.cmd` — มันจะก๊อปเกมเวอร์ชันล่าสุดจาก `C:\Tae`
มาที่นี่ แล้วส่งขึ้นเว็บให้เอง รอสักครู่หน้าเว็บก็จะเปลี่ยนตาม

> ประวัติการแก้เกมทั้งหมด (จุดเซฟ) อยู่ในคลังหลักของเต้ที่เครื่องนะ
> ที่นี่เก็บไว้แค่ตัวเกมที่เล่นได้ เอาไว้แชร์ให้เพื่อน
